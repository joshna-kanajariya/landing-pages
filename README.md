# HeartSync Counseling Landing Page

A supportive, connection-focused landing page for relationship counseling platform "HeartSync Counseling".

## Features

### Design & Visual Elements
- **Relationship Colors**: Warm rose (#E67E7E), trust blue (#4A90E2), healing green (#7ED321)
- **Heart and Connection Imagery**: CSS-based heart shapes and connection visualizations
- **Compassionate Typography**: Source Sans Pro mixed with Merriweather for warmth and readability
- **Mobile-First Responsive Design**: Optimized for all devices

### Interactive Components

#### Hero Section
- **Animated Relationship Health Assessments**: Progress bars showing communication quality, emotional connection, and conflict resolution
- **Floating Communication Improvement Displays**: Animated cards showing active listening improvements, empathy scores, and connection strength
- **Couple Therapy Session Atmosphere Previews**: Visual representation of therapy environment

#### Interactive Tools
- **Relationship Compatibility Meter**: Interactive tool that calculates compatibility percentage with animated counting
- **Personalized Counseling Plan Suggestions**: Dynamic recommendations based on compatibility assessment
- **Communication Exercise Libraries**: Comprehensive collection of relationship-building exercises with progress tracking

#### Therapist Showcase
- **Scroll-Triggered Animations**: Therapist cards animate into view as user scrolls
- **Specialization Credentials**: Display of certifications (Gottman Method, EFT, IMAGO)
- **Success Story Animations**: Animated success rate displays and testimonials

#### Progress Tracking
- **Relationship Goal Tracking**: Visual dashboard showing progress in various relationship areas
- **Communication Exercise Libraries**: Interactive exercise library with difficulty levels
- **Progress Monitoring**: Real-time tracking of relationship improvement metrics
- **Milestone Celebrations**: Achievement badges and streak tracking

### Content Sections

1. **Navigation**: Smooth scrolling navigation with active states
2. **Hero Section**: Main value proposition with interactive health check
3. **Compatibility Tool**: Interactive relationship assessment
4. **Therapist Showcase**: Expert therapist profiles with credentials
5. **Methodology Explanations**: Proven therapy approaches with effectiveness rates
6. **Success Stories**: Testimonial galleries with breakthrough celebrations
7. **Counseling Packages**: Three-tier pricing with session frequency options
8. **Progress Tracking**: Goal tracking and exercise library
9. **Footer**: Contact information and resource links

### Technical Implementation

- **Single File Structure**: All HTML, CSS, and JavaScript in one file
- **CDN Resources**: Tailwind CSS, Google Fonts, Font Awesome icons
- **Performance Optimized**: Efficient animations and lazy loading
- **Accessibility Features**: ARIA labels, keyboard navigation, reduced motion support
- **Modern Animations**: CSS keyframes and JavaScript interactions

### Animations & Interactions

- **Floating Elements**: Communication improvement displays with delayed animations
- **Progress Bars**: Animated progress indicators for relationship health metrics
- **Compatibility Meter**: Animated percentage counting with visual feedback
- **Scroll Reveals**: Content animates into view on scroll
- **Heart Pulse**: CSS-based heart animations for emotional connection
- **Hover Effects**: Interactive card and button animations

## Usage

Simply open `index.html` in a web browser. The page is fully self-contained and includes all necessary resources via CDN links.

For development, you can serve it using a simple HTTP server:

```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000`

## Browser Compatibility

- Modern browsers with CSS Grid and Flexbox support
- Responsive design works on mobile, tablet, and desktop
- Graceful degradation for older browsers
- Accessibility compliant with keyboard navigation support
