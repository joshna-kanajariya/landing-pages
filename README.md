# FlowState Mastery Landing Page

A comprehensive, productivity-focused landing page for the "FlowState Mastery" service. Built with modern web technologies and optimized for conversion and user experience.

## Features

### 🎯 Core Functionality
- **Animated Hero Section** with productivity workflow demonstrations
- **Interactive Productivity Assessment** with personalized recommendations
- **Expert Coach Profiles** with methodology expertise
- **Client Testimonials** with metrics and achievements
- **Pricing Tiers** with feature comparisons
- **Habit Tracking Integration** with challenges and analytics

### 🎨 Design Elements
- **Productivity Color Scheme**: Focus Blue (#2563eb), Energy Orange (#ea580c), Efficiency Green (#059669)
- **Typography**: Roboto + Source Sans Pro with clean hierarchy
- **Workflow Diagram Backgrounds** and time optimization graphics
- **Floating Animation Elements** for enhanced visual appeal

### 📱 Technical Features
- **Single File Structure** with embedded CSS and JavaScript
- **Mobile-First Responsive Design** 
- **Accessibility Features** with ARIA labels and keyboard navigation
- **Performance Optimized** with CDN resources and efficient animations
- **Scroll-Triggered Animations** with reduced motion support

### 🛠 Technologies Used
- **HTML5** semantic markup
- **Tailwind CSS** via CDN for styling
- **Vanilla JavaScript** for interactions
- **Google Fonts** (Roboto + Source Sans Pro)
- **Font Awesome** icons

## Getting Started

Simply open `index.html` in a web browser. No build process or dependencies required.

- ARIA labels for screen readers
