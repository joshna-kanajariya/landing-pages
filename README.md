# CarbonSense Monitor - Landing Page

An impactful, awareness-focused landing page for the carbon tracking app "CarbonSense Monitor". This landing page promotes environmental consciousness through interactive tools, expert insights, and community-driven climate solutions.

## 🌍 Features

### Climate-Focused Design
- **Climate Colors**: Earth green (#2D5016), warning orange (#FF6B35), and sky blue (#87CEEB)
- **Typography**: Inter mixed with Roboto Slab for impactful presentation
- **Environmental Emojis**: Tree, leaf, and environmental icons throughout

### Interactive Components
- **Animated Personal Carbon Calculator**: Real-time calculation display in hero section
- **Floating Emission Reduction Goals**: Animated goal badges showing progress
- **Climate Impact Timeline**: Scroll-triggered timeline demonstrating long-term impact
- **Interactive Lifestyle Assessment Tools**: Live sliders for transport, home energy, and diet impact
- **Action Plan Builder**: Checkbox challenges with dynamic progress tracking

### Content Sections
1. **Hero Section**: Animated carbon footprint calculations with emission goals
2. **Climate Impact Timeline**: 4-stage journey from today to carbon negative
3. **Lifestyle Assessment Tools**: Interactive carbon footprint calculators
4. **Sustainability Expert Advisors**: 3 expert profiles with environmental backgrounds
5. **Success Stories**: User testimonials with environmental impact metrics
6. **Action Plan Builder**: Personalized sustainability challenges
7. **Community & Partnerships**: Global community stats and environmental projects
8. **Call to Action**: App download promotion with compelling messaging

## 🚀 Technology Stack

- **HTML5**: Semantic structure with accessibility features
- **CSS3**: Custom animations and responsive design
- **JavaScript**: Interactive features and scroll-triggered animations
- **Tailwind CSS**: Utility-first styling framework (CDN)
- **Google Fonts**: Inter and Roboto Slab typography (CDN)
- **Font Awesome**: Environmental and UI icons (CDN)
