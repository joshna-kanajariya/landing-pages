# CryptoCanvas - Premium NFT Marketplace

A vibrant, premium NFT marketplace landing page built with modern web technologies and featuring an artistic, experimental design.

## 🎨 Features

### Design & Aesthetics
- **Vibrant Gradients**: Hot pink to electric blue color scheme throughout
- **Custom Cursor Effects**: Colorful trailing cursor with smooth animations
- **Animated Polygon Backgrounds**: Color-shifting geometric elements
- **Bold Experimental Typography**: Custom font combinations with text animations
- **Dark Theme**: Modern dark background with vivid accent colors

### Interactive Elements
- **3D NFT Showcases**: Rotating gem display in hero section with 3D transforms
- **Parallax Scrolling**: Multi-layer scrolling effects for immersive experience
- **Hover Effects**: Smooth transitions revealing NFT details on card hover
- **Interactive Minting Simulator**: Functional NFT creation process simulation
- **Magnetic Scroll Snap**: Collections carousel with smooth snap behavior

### Content Sections
- **Hero Section**: Prominent branding with call-to-action buttons
- **Trending Collections**: Horizontal scrolling showcase of popular NFT collections
- **Creator Spotlight**: Featured artist profiles with statistics
- **Minting Interface**: Complete form for NFT creation simulation
- **Community Feed**: Simulated social media integration
- **Crypto Price Ticker**: Live-updating cryptocurrency prices
- **Community Statistics**: Dynamic marketplace metrics

### Technical Features
- **Single File Architecture**: Self-contained HTML with embedded CSS and JavaScript
- **Mobile-First Responsive**: Optimized for all device sizes
- **Performance Optimized**: Efficient animations and lazy loading
- **Accessibility Compliant**: ARIA labels, keyboard navigation, reduced motion support
- **No External Dependencies**: Works offline without CDN requirements
- **Modern Browser Support**: Uses latest CSS and JavaScript features

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/joshna-kanajariya/landing-pages.git
   cd landing-pages
   ```

2. **Open in browser**
   ```bash
   # Using Python
   python3 -m http.server 8080
   
   # Using Node.js
   npx serve .
   
   # Or simply open index.html in your browser
   ```

3. **Visit the site**
   Open `http://localhost:8080` in your web browser

## 🎯 Key Interactions

- **Custom Cursor**: Move your mouse to see colorful trailing effects
- **3D Gem Animation**: Watch the rotating NFT showcase in the hero section
- **Collection Cards**: Hover over trending collections for 3D tilt effects
- **Minting Simulator**: Click "Mint NFT" to see the interactive creation process
- **Smooth Navigation**: Use navbar links for smooth scroll to sections
- **Price Updates**: Watch cryptocurrency prices update dynamically
- **Responsive Menu**: Mobile hamburger menu for smaller screens

## 🛠 Technology Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript ES6+
- **Styling**: Custom CSS with Tailwind-inspired utilities
- **Icons**: Unicode emoji symbols for universal compatibility
- **Fonts**: Google Fonts (Inter, Space Grotesk, Orbitron) with fallbacks
- **Animations**: CSS keyframes and JavaScript intersection observers
- **Responsive**: CSS Grid and Flexbox for layout
